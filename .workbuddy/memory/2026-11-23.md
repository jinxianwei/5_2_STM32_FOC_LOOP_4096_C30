# 2026-11-23

- 完成项目整体分析：STM32F407 + HAL，20 kHz FOC 控制周期为 TIM1 更新中断；采样链为 ADC1-DMA 两相电流+母线电压/NTC/电位器，角度源为 TLE5012 磁编码器（SPI1）。
- 控制模式集中在 motor_ctrl.c / MotorModeSel：有感速度/电流/位置环、无感 HFI→SMO/Flux、IF 启动、IF→观测器切换、六步方波开环/速度/电流环；观测器切换采用 UpTime/DownTime + 角度误差滞回与 PLL 同步。
- 关键风险：中断内软件 SPI 读编码器、USART1 中断内忙等、ADC 零点校准耗时约 1 s、FaultCheck 在正常态清空故障字、无硬件过流/刹车联动。
- 六步电流环转矩偏小排查：电流给定上限与过流阈值同为 5 A，满给定触发积分器反复清零；浮空相六步沿用了速度环的 180° 相位补偿，与实际矢量中心差 30°（后续如需再排查，做相位角扫参）。
- 已落地三处低风险修改（未动换向角度）：motor_para.h 中 SIX_STEP_CURRENT_REF_MAX 5→4 A；motor_ctrl.c 电流反馈由三相最大绝对值改为 (|Iu|+|Iv|+|Iw|)*0.5；异常分支积分器由硬清零改为 *0.9 缓慢泄放。待实测验证转矩改善。
